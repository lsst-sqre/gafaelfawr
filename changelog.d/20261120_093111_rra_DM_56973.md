### Backwards-incompatible changes

- Use HTTPX2 instead of HTTPX in the Gafaelfawr client. Callers that pass in an existing client must now pass in an HTTPX2 client, and tests that mock out the Gafaelfawr results must now use pytest-httpx2 and its `httpx2_mock` fixture instead of using the `respx_mock` fixture directly.
