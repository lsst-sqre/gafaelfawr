### New features

- Add GitHub project templates and provisioning for the GitHub Actions OIDC token exchange. Token administrators define templates at `/auth/api/v1/github/project-templates` that fix every field of a project except the repository and restrict the repositories to a set of GitHub owners (pinned by numeric ID) and an optional name pattern. A service holding the new `admin:github-oidc-provision` scope, or `admin:token`, can then create a project from a template with `POST /auth/api/v1/github/project-templates/{name}/projects`, supplying only the repository. Provisioning is idempotent for a repository already provisioned from the same template, and template changes are recorded in the project history.
