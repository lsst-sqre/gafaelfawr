### New features

- Add the registry of GitHub projects for the GitHub Actions OIDC token exchange: models, storage, and a service that derives bot usernames, pins repository IDs from the GitHub API, refuses overlapping projects, records changes in the project history, and revokes a project's tokens when it is disabled or deleted. Tokens minted for a GitHub project record the project ID in token information and the token change history. The admin API and exchange endpoint are not yet implemented.
