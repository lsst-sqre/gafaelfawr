### New features

- Add the registry of GitHub projects for the GitHub Actions OIDC token exchange: models, storage, and a service that derives bot usernames, pins repository IDs from the GitHub API, refuses projects whose constraints overlap an enabled project for the same repository, records changes in the project history, and revokes a project's tokens when it is disabled or deleted. Tokens minted for a GitHub project record the project ID in token information and the token change history, and the audit reports (and with `--fix` revokes) tokens whose project no longer exists. The admin API and exchange endpoint are not yet implemented.
