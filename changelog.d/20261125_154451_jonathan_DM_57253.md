### New features

- Add an admin route, `GET /auth/api/v1/tokens`, that lists tokens across all users. It requires the `admin:token` scope. The listing can be filtered by token type, by username or username prefix, and by one or more scopes, all of which a token must have. It can be sorted by creation time or by username, and paginated with `limit` and `cursor`, in which case the reply includes `Link` and `X-Total-Count` headers.
