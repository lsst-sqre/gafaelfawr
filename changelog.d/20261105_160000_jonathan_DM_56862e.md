### New features

- Add the GitHub Actions token exchange endpoint at `POST /auth/api/v1/github/token`, following the OAuth 2.0 token exchange grammar of RFC 8693. A GitHub Actions workflow can exchange the ID token that GitHub issued to its job for a Gafaelfawr token of the new `github` type, issued to the bot user of the enabled GitHub project whose constraints the ID token satisfies, with the project's scopes (or a requested subset) and lifetime. Each exchange is recorded in the token change history and as a `github_token_exchange` metrics event that ties the token to the workflow run. The exchange is available only when `config.githubTokenExchange.enabled` is set.
