### Backwards-incompatible changes

- Replace the previous Cloud SQL support with native support, which significantly changes the Helm chart configuration for environments that use Cloud SQL. Settings are now under `config.database` instead of `cloudsql`.
- Cloud SQL deployments must use IAM authentication to the database rather than username and password authentication. The Gafaelfawr service account must now also have the `roles/cloudsql.instanceUser` role.
- Rename the `config.databaseUrl` setting to `config.database.url`.

### New features

- Add native Cloud SQL support that uses IAM authentication to the database instead of a password. Manage the database connection with native Python code instead of using the Cloud SQL Auth Proxy.
